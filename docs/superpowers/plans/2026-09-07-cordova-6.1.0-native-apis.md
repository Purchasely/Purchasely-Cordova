# Cordova 6.1.0: anonymous user id, API proxy, Web2App redemption

**Created:** 2026-09-07
**Completed:** 2026-09-07 (PR #73)
**Spec:** `Purchasely/Purchasely-React-Native` PR #293 (`feat/6.1.0-native-apis`). That PR is
the reference contract. This plan adapts it to Cordova.

## Goal

Bring the Cordova SDK to Purchasely 6.1.0: the four new start options, the Web2App
redemption listener, and the two redemption analytics events. Native pins: iOS pod
`6.1.0`, `io.purchasely:*:6.1.0`.

## Scope

| Item | iOS | Android |
|------|-----|---------|
| `anonymousUserId` + `anonymousUserIdOverride` | yes | yes |
| `proxy` | no. MOB-308 is not in iOS 6.1.0. The bridge ignores it | yes |
| `appHandlesRedemptionAlert` | yes | yes |
| `addWebRedemptionListener` / `removeWebRedemptionListener` | yes | yes |
| `REDEMPTION_CONSUMED` / `REDEMPTION_FAILED` | pass-through | pass-through |

## Where Cordova differs from React Native

1. **The listener is an `exec` action, not an event emitter.** `addWebRedemptionListener`
   stores a Cordova `callbackId`, the way `addEventsListener` does. The native delegate
   still goes on the builder chain at `start()`, because neither native SDK has a runtime
   setter. So the app must call `addWebRedemptionListener` **before** `start()`. Cordova
   dispatches `exec` calls in order, so the callbackId is stored first.
2. **The subscription mapper is Cordova's own.** `transformSubscriptionsToJson` applies
   `normalizeProductPlans`, `transformPlanToMap` and the CDV-W-15 `NONE` /
   `WEB_CHECKOUT_STRIPE` → `4` rule. Extract a per-item helper from it, do not copy the
   React Native one.
3. **The two new events need no bridge work.** iOS maps the enum with the SDK's own
   `[NSString fromPLYEvent:]`, and Android forwards `event.properties.toMap()`. Both
   carry the new names and the `redemption` payload as they are.
4. **No type declarations to fix.** Cordova ships plain JavaScript, so the React Native
   `PLYSubscription.purchaseToken` optionality fix has no Cordova counterpart.

## Steps

1. JS: the three builder modifiers, the two listener methods, the `start(options)`
   contract comment.
2. iOS: `PLYWebRedemptionDelegate` on the Events category, the delegate callback, the
   `start:` option parsing, the two actions.
3. Android: `parseCanonicalUuid`, `webRedemptionResultToMap`, the extracted subscription
   mapper, the `start()` option parsing, the two actions.
4. Tests: Jest for the JS surface, XCTest in `example-capacitor` for the iOS delegate
   conformance. Android has no unit-test module in this repository, so `build-android`
   in CI is its compile gate.
5. Example app: the listener before `start()`, `appHandlesRedemptionAlert: false`,
   `anonymousUserId` and `proxy` as commented call sites.
6. Docs: a 6.1.0 section in `README.md`.
7. Release: bump every file `RELEASE.md` lists, plus `purchasely-google/package-lock.json`,
   and add the `VERSIONS.md` row.
