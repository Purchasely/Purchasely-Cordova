# Cordova 6.0.0 — release iso + doc exhaustive (plan maestro)

**Date:** 2026-07-24 · **Branche:** `feat/migration-v6` (PR #57, base `main`, approved, CI green).

## Constat (audit compréhension)

- **Pins natifs déjà release** : iOS pod `6.0.0`, Android `io.purchasely:core`/`google-play` `6.0.1`. `mavenLocal()` retiré des sources.
- **Version plugin encore RC** : `6.0.0-rc.3`. Le check CI « Version Consistency » compare **9 chaînes / 6 fichiers** (voir LOT 1D).
- **Cœur d'API en vraie parité** avec RN (`feat/sdk-v6-migration`) et Flutter (`main`) : `start(options)`, builder `Purchasely.presentation.placement/.screen/.defaultSource().build().preload()/.display()`, `interceptAction` par kind, outcome 5 champs, deeplinks, attributs, produits/plans, abonnements, dynamic offerings, commitment Apple.
- **Outcome vérifié iso** : `purchaseResult` string (`purchased|cancelled|restored`) émise par les 2 bridges natifs ; `result` (int) legacy émis nativement mais **supprimé par `normalizeOutcome` en JS** → invisible au dev.
